# Code of Conduct

## The short version

Be decent. This is a small tool maintained in spare time; disagreement about code is welcome,
disrespect towards people is not.

## Expected

- Assume good faith and ask questions before assuming someone is careless.
- Keep reviews about the code and the evidence, not the person.
- Respect that the maintainer may decline a change to keep the tool small.

## Not acceptable

- Harassment, insults, or personal attacks, public or private.
- Sexualised language or imagery, or unwelcome attention of any kind.
- Publishing someone's private information without permission.

## Scope

Issues, pull requests, discussions and any other space where someone is representing this
project.

## Enforcement

Report a problem to the maintainer ([@chaoticpunk](https://github.com/chaoticpunk)) — privately
if the report involves someone's safety. Reports are read in confidence. Depending on severity
the response is a warning, a temporary block, or a permanent ban from the project's spaces.
